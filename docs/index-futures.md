# 沪深 300 股指期货回放（IF）

通过 `engine.index_futures.replay_if` 回放单个月份 IF 合约。NautilusTrader 1.231.0 负责委托与成交；期货账本按独立的 CNY 保证金、逐日结算和现金交割规则记账。每个交易日核对原生净持仓与期货账本持仓。普通股票入口无需加载此模块。

| 输入 | 约定 |
|---|---|
| `IFContract` | IF 月份代码、上市日和最后交易日；每点 ¥300，报价步长 0.2 点 |
| `IFDay` | 按交易日顺序提供完整回放区间的开盘价、结算价、价格上下限和开盘可成交手数；到期持仓须提供交割结算价 |
| `IFOrder` | 提前确定的执行日、买卖方向、手数，以及开仓、平今或平昨；同日按输入顺序处理 |
| `IFPolicy` | 本次回放适用的保证金比例和开、平今、平昨、交割费率，均为显式输入；可传固定政策，或传 `{生效日: IFPolicy}` 的阶梯表。首交易日须有覆盖；各日选择最近已生效的条目，日终行保留生效政策 |

日终现金只结转一次持仓与当日成交的结算盈亏。占用保证金从可用资金扣除，不作为费用。出现保证金缺口时，结果保留负的可用资金，后续新增风险委托受保证金约束。到期持仓按提供的交割结算价结清并释放保证金。

```powershell
python examples/validate_if_tushare.py --root "C:\path\to\Tushare_DB"
```

示例只读使用 IF2306 的真实行情、合约元数据和到期日结算字段，逐日独立复算一手空仓至到期的现金与保证金；容量采用前一有效交易日成交量的代理，保证金与费用使用明示情景参数，并在 6 月 15 日切换至新参数。场景末日现金 ¥961,046.67，保证金和持仓均归零。

首版采用开盘单窗口、全成或拒单模型。缺少盘口时，开盘容量和封板处理是研究假设。同日平今用于同一窗口内的顺序委托；盘中执行、分批成交、自动强平、换月和股票组合对冲另行验收。

参考：[中金所结算细则](https://www.cffex.com.cn/u/cms/www/202501/071747590uho.pdf)、[沪深 300 股指期货合约交易细则](https://www.cffex.com.cn/u/cms/www/202003/27165436e0mo.pdf)。
