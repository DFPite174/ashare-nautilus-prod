# 中金所股指期货回放（IF、IH、IC、IM）

通过 `engine.index_futures.replay_if_portfolio` 回放一个期货账户下的多个真实合约。单合约可用 `replay_if`。NautilusTrader 1.231.0 负责委托与成交。期货账本计算保证金、逐日盯市和到期现金交割，在交割前核对原生净持仓，并核对原生到期回报的方向、手数和交割价。普通股票仍走自己的执行入口，两类资产可以合并查看净值和敞口。

| 输入 | 约定 |
|---|---|
| `IFContract` | 真实月份代码、上市日和最后交易日。`IF` / `IH` 每点 ¥300，`IC` / `IM` 每点 ¥200，报价步长均为 0.2 点 |
| `IFDay` | 按交易日提供开盘价、结算价、价格上下限和开盘可成交手数。持仓交割须显式提供交易所交割结算价。传入 `trading_days` 可核对完整的回放日历 |
| `IFOrder` | 已确定的执行日、方向、手数和开平标志。多合约入口接收 `(symbol, order)`，同日按输入顺序处理。`depends_on` 指向同日更早的输入序号，从 0 开始。`allow_partial=True` 启用共享开盘容量下的部分成交 |
| `IFPolicy` | 显式提供保证金比例和开仓、平今、平昨、交割费率。`submission_fee` 为实际提交给模拟交易所的每笔固定申报费，默认零。支持固定政策、生效日表和按合约覆盖 |
| `margin_groups` | 为符合条件的品种显式指定互不重叠的抵扣组，例如 `[("IF", "IH", "IC", "IM")]`。每组先分别汇总多、空的交易保证金，再取较大的一边。组外按合约相加，默认全部逐约相加 |
| `cash_deposits` | 回放交易日到补资金额的映射。补资在当日开盘风控之前到账，独立记录于日终账户 |

**开盘风控。** `IFPolicy` 可配置 `max_order_lots`（原始委托手数）、`max_position_lots`（同合约净持仓上限）和 `max_daily_open_lots`（同合约当日累计开仓成交）。后两项按可执行手数判断。平仓释放持仓额度，当日累计开仓额度按交易日重置。按合约和生效日配置适用上限，默认由调用方选择。可选的 `limit_price` 按 0.2 点校验，在价格带内且开盘可成交时送入原生撮合。

**审计。** 使用 `audit=True`，同时指定 `data_snapshot_id` 和 `capacity_model`。结果的 `evidence` 保存输入、输出和实现的 SHA-256、NautilusTrader 版本，以及逐单请求、开盘价与剩余容量、成交时间和手数、费用或拒单原因。可用 `engine.reproducibility.canonical(result.evidence)` 导出为 JSON 兼容对象。常规回放默认关闭审计计算。

**换月。** 将旧月平仓排列在新月开仓之前。需要联动时，在新月订单上填写旧月平仓的 `depends_on`。只有收到前置订单完整的原生成交回报才提交新月腿，部分成交或拒单返回 `DEPENDENCY_UNFILLED`。这是同一开盘窗口的顺序回放。新月腿自身仍可能因容量或资金失败；结果记录实际仓位。

**成交与费用。** 默认全成或拒单。允许部分成交时，按剩余开盘容量提交可执行手数，成交记录的 `lots` 为实际手数，`unfilled_lots` 记录部分成交的剩余手数。费用按成交金额计提，固定申报费只对通过回放前置检查并提交给原生引擎的订单收取。成交与拒单的输入索引可通过 `order_symbols` 定位合约。

**日终账户。** 现金反映结算盈亏、费用和外部补资。可用资金等于现金减占用保证金。`gross_margin` 单列无抵扣的保证金，`margin_shortfall` 记录资金缺口，主动减仓仍可执行。名义敞口以结算价计量，带多空符号，交割后归零。

```powershell
python examples/validate_if_tushare.py --root "C:\path\to\Tushare_DB"
```

示例只读使用本地 Tushare 的 2023 年行情，分别复算 `IF2306` 空仓交割、`IF2306 → IF2307` 换月、四品种共享保证金与同日交割，以及股票持仓的股指期货对冲。交割价格与中金所公告逐项核对。对冲手数使用前一日股票敞口和期货结算价，股票与期货分别预拨资金，合并净值为两个账户的权益之和。

**回放口径。** 日频单开盘窗口、单合约净头寸。示例使用前一日成交量估计开盘容量，并显式提供情景限价、费率和保证金。真实竞价排队、交易所原子价差单、经纪商撤单收费与强平属于独立的成交或风控模型。抵扣组与费用应按历史生效规则及实际交易编码配置。
