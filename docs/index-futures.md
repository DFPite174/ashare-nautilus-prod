# 中金所股指期货回放（IF、IH、IC、IM）

通过 `engine.index_futures.replay_if_portfolio` 回放一个期货账户下的多个真实合约。单合约可用 `replay_if`。NautilusTrader 1.231.0 负责委托与成交。期货账本计算保证金、逐日盯市和到期现金交割，并在日终交割前核对原生净持仓。普通股票仍走自己的执行入口，两类资产可以合并查看净值和敞口。

| 输入 | 约定 |
|---|---|
| `IFContract` | 真实月份代码、上市日和最后交易日。`IF` / `IH` 每点 ¥300，`IC` / `IM` 每点 ¥200，报价步长均为 0.2 点 |
| `IFDay` | 按交易日提供开盘价、结算价、价格上下限和开盘可成交手数。持仓交割须显式提供交易所交割结算价。传入 `trading_days` 可核对完整的回放日历 |
| `IFOrder` | 已确定的执行日、方向、手数和开平标志。多合约入口接收 `(symbol, order)`，同日按输入顺序处理 |
| `IFPolicy` | 显式提供保证金比例和开仓、平今、平昨、交割费率。支持固定政策或 `{生效日: IFPolicy}`，也可通过 `contract_policies` 按合约覆盖。每份生效表须覆盖相应的首个回放日 |

**换月。** 将旧月平仓、新月开仓按顺序提交。两腿各自成交或拒单，结果保留实际仓位。仅已接受的旧月平仓可为后续开仓释放保证金。成交与拒单记录的索引可通过 `order_symbols` 定位合约。

**日终账户。** 现金反映结算盈亏和费用。可用资金等于现金减占用保证金。负的可用资金保留在结果中，减仓仍可执行。`positions`、`notionals`、`deliveries`、`contract_policies` 提供逐合约结果。名义敞口以结算价计量，带多空符号，交割后归零。

```powershell
python examples/validate_if_tushare.py --root "C:\path\to\Tushare_DB"
```

示例只读使用本地 Tushare 的 2023 年行情，分别复算 `IF2306` 空仓交割、`IF2306 → IF2307` 换月、四品种共享保证金与同日交割，以及股票持仓的股指期货对冲。交割价格与中金所公告逐项核对。对冲手数使用前一日股票敞口和期货结算价，股票与期货分别预拨资金，合并净值为两个账户的权益之和。

**回放口径。** 日频单开盘窗口、全成或拒单、单合约净头寸、跨合约保证金相加。示例使用前一交易日成交量估计开盘容量，并显式提供情景限价、费率和保证金。盘中订单、部分成交、自动强平和交易所组合保证金属于后续建模范围。
